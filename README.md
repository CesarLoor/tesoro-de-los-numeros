# Tesoro de los Números

Juego de matemáticas para niños con temática pirata. Hay cuatro islas, una por operación (suma, resta, multiplicación y división). Cada isla tiene 5 retos que van de fácil a difícil, y al final se abre el cofre del tesoro.

**Jugar:** https://cesarloor.github.io/tesoro-de-los-numeros/

## Archivos

- `tesoro-de-los-numeros.html`: el juego completo (HTML, CSS y JS, sin dependencias).
- `PROPUESTA.md`: diseño del juego, niveles, puntuación y reglas de variedad.
- `.github/workflows/deploy.yml`: publica el juego en GitHub Pages con cada push a `main`.

## Probar en local

Abre `tesoro-de-los-numeros.html` en el navegador, o sirve la carpeta:

```bash
python -m http.server 8000
```
